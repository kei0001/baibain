# バイバイまんじゅうを食い切れ

増殖するまんじゅうを、ひとつ残らず食べるブラウザ向けアホゲー。
依存パッケージ不要。HTML / CSS / JavaScript、Canvas描画、Web Audioの効果音。

## 遊ぶ

```sh
npm start
```

http://localhost:5178 を開きます（Python 3 が必要）。任意の静的ホスティングでも動きます。

- クリック / Space：ひとくち。0.7秒以内の連打8回ごとに3個食い。
- B / 別腹ボタン：満腹ゲージを一度だけリセット。
- おやつ：24個、5秒ごとに倍増。大食い：48個、4.5秒。無理：52個、4秒。
- 全部食べれば勝利。1,024個に達すると敗北。
- 満腹になると食べられません。休むと回復します。
- タブを離れると自動停止。難易度を変えると最初から。
- 最速記録はブラウザ内に保存。音は初期状態でオフ。

## テスト

```sh
npm test
```

Node.js 18以降。増殖、満腹、別腹、勝敗、各難易度のクリア可能性を検証。
