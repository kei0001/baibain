# バイバイまんじゅうを食い切れ

倍々に増えるまんじゅうを食べ、胃袋を進化させて逆転するブラウザ向けアホゲー。

**遊ぶ → https://kei0001.github.io/baibain/**

## 操作とルール

- クリック / Space：ひとくち。0.7秒以内の連打8回ごとに3倍食い。
- 累計20 / 50 / 100 / 220個で進化。一口が2 / 5 / 10 / 20個に。
- B / お茶ボタン：1.5秒間は食べられないが、飲み終わると満腹解消＋4秒間、一口2倍・満腹増加なし。
- お茶は開始から7.5秒で再使用可能。飲んでいる間も増殖は続く。
- おやつ：48個・6秒ごとに倍増。大食い：96個・5秒。無理：160個・4.5秒。
- 全部食べれば勝利。残り1,024個で敗北。増殖しても進化は維持。
- タブを離れると自動停止。難易度変更でリセット。音は初期状態でオフ。
- 最速記録はブラウザ内に保存。ルール変更前の記録とは別に保存。

## ローカルで動かす

```sh
npm start
```

Python 3が必要。http://localhost:5178 を開く。依存パッケージ不要のHTML / CSS / JavaScript。

## 検証

```sh
npm test
```

Node.js 18.12以降。増殖、満腹、進化、お茶の待ち時間と効果終了、勝敗、増殖後の逆転を検証。
おやつは毎秒2回の入力、大食いは3回、無理は4回程度とお茶の活用で完食できることをシミュレーション確認。
