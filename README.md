# バイバイまんじゅう：増やし切れ / 食い切れ

倍々に増えるまんじゅうを食べ、胃袋を進化させて逆転するブラウザ向けアホゲー。

**遊ぶ → https://kei0001.github.io/baibain/**

## まんじゅうモード（トップページ）

自動で食べてくる人間に対し、90秒以内に仲間を1,024個まで増やせば勝利。0個または時間切れで敗北。

- タップ / Spaceで倍増を通常0.08秒、満腹中0.25秒、お茶中0.4秒早める（受付間隔0.12秒以上）。応援パワーを8消費し毎秒12回復。自然増殖も進む。
- 人間は満腹85以上で食事停止。一定時間ごとに2秒のお茶休憩→満腹解消と3秒の爆食い。
- 結果スコア = 生まれた数 + 食べられた数×3 + 生存秒数×2 + 勝利ボーナス300。
- 獲得XP = スコア÷15の切り捨て（最低1）。終了時に一度だけ受け取る。
- 増殖力：倍増時間7秒から、Lvごとに0.4秒短縮。
- でかさ：一口の先頭4個までは1個あたり満腹7＋Lv×2。その先は追加個数の平方根×2。見た目も成長。
- あんこの重さ：相手の満腹回復をLvごとに6%減少。
- 各強化は最大Lv.8。購入費用は35 + 現在Lv×25 XP。試合中は購入・相手変更不可。
- 少食→腹ペコ→大食い王。勝利で次の相手が解放。以前の相手にも再戦できる。
- 初期個数は相手ごとに12 / 20 / 28。人間の一口は個数に応じて増加（少食3.5%、腹ペコ6.5%、王12%、元の一口が下限）。最大個数が128増えるごとに消化速度も60%ずつ増加。
- 初戦は未強化・毎秒2タップで勝利可能。王は全強化Lv.6の場合、毎秒5回の常時連打は敗北し、お茶・満腹・パワー90超だけ応援する入力は勝利するシミュレーションを確認。最大強化なら攻略しやすくなる。
- XP、強化、解放状況はこのブラウザのlocalStorageに保存。保存不可の場合は育成室に表示。
- 一時停止とタブ非表示の自動停止に対応。初戦終了後は育成室で強化して再戦。

## 人間モード

`human.html` で従来の食べる側も遊べます。以下は人間モードのルールです。

## 操作とルール

- クリック / Space：ひとくち。0.7秒以内の連打8回ごとに3倍食い。
- 累計20 / 50 / 100 / 220個で進化。一口が2 / 5 / 10 / 20個に。
- B / お茶ボタン：1.5秒間は食べられないが、飲み終わると満腹解消＋4秒間、一口2倍（満腹は増える）。
- お茶は開始から7.5秒で再使用可能。飲んでいる間も増殖は続く。
- おやつ：48個・6秒ごとに倍増。大食い：96個・5秒。無理：160個・最初は4.5秒、倍増ごとに0.25秒短縮、最短3秒。
- 満腹増加は一口ごとに `6 + 2 × √(実際に食べた個数)`。進化・爆食い・コンボで大量に食べるほど増加。毎秒12回復。
- 全部食べれば勝利。残り1,024個で敗北。増殖しても進化は維持。
- タブを離れると自動停止。難易度変更でリセット。音は初期状態でオフ。
- 最速記録はブラウザ内に保存。ルール変更前の記録とは別に保存。

## ローカルで動かす

```sh
npm start
```

Python 3が必要。http://localhost:5178 を開く。依存パッケージ不要のHTML / CSS / JavaScript。

## 検証

```sh
npm test
```

Node.js 18.12以降。増殖、満腹、進化、お茶の待ち時間と効果終了、勝敗、増殖後の逆転を検証。
「無理」は毎秒6回・満腹50付近でお茶を使う入力で逆転勝利、同じ速度で満腹80まで待つ入力は敗北。お茶なしの毎秒3 / 5 / 8 / 12回連打は敗北を確認。これは固定入力のシミュレーションであり、体感難度や全戦略の保証ではありません。
